📡 PROTOCOLO BLUETOOTH
═══════════════════════════════════════════════════════════════════════════════

COMANDOS ENVIADOS (App → ESP32):
  EST,<1-7>*       → Seleciona estratégia
  VR,<0-255>*      → Velocidade reta
  VG,<0-255>*      → Velocidade giro
  HBE,<0|1>*       → Evasão por impacto
  LIP,<0-100>*     → Limiar parado
  LIE,<-100-0>*    → Limiar empurrão
  PARADA*          → Para todos motores
  dados*           → Solicita telemetria
  CALIBRAR*        → Calibra IMU
  
  [Novos comandos implementados no app, aguardam firmware:]
  FRENTE,<vel>*    → Move frente (teste)
  RE,<vel>*        → Move ré (teste)
  ESQUERDA,<vel>*  → Gira esquerda (teste)
  DIREITA,<vel>*   → Gira direita (teste)
  TESTE_MOTOR,*    → Testa motor individual
  LED,<1|2>,<0|1>* → Controla LEDs

TELEMETRIA RECEBIDA (ESP32 → App):
  Formato: velocreta|velocgiro|HBE|limiarParado|limiarEmpurrado|Vbat|
           sen_dir|sen_centro_dir|sen_centro_esq|sen_esq|sensorLD|sensorLE
  
  Exemplo: 200|180|1|10|-25|11.8|0|1|1|0|1024|2048
  
  Campos (12 valores):
   1. velocreta      (0-255)
   2. velocgiro      (0-255)
   3. HBEvasao       (0/1)
   4. limiarParado   (0-100)
   5. limiarEmpurrado (-100-0)
   6. Vbat           (volts, ex: 11.8)
   7. sen_dir        (0/1)
   8. sen_centro_dir (0/1)
   9. sen_centro_esq (0/1)
  10. sen_esq        (0/1)
  11. sensorLD       (0-4095)
  12. sensorLE       (0-4095)
